## Project Overview

Enterprise DFIR is designed to support structured digital forensic investigations and incident response workflows through a centralized web interface.

## Key Features

- User Registration and Authentication
- Digital Evidence Upload and Management
- SHA-256 Evidence Integrity Verification
- Chain of Custody Tracking
- Forensic Timeline Reconstruction
- Security Event Alerts
- Incident Management and Investigation
- User-Specific Evidence and Investigation Records

## Technology Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, Bootstrap, Jinja2
- **Database:** SQLite
- **Security:** Werkzeug, CSRF Protection, SHA-256
- **Deployment:** Render
- **Production Server:** Gunicorn

## Simulated APT Investigation

The project includes a planned controlled APT attack simulation using synthetic enterprise security events, with investigation activities covering:

- Attack event analysis
- Evidence collection and integrity verification
- Attack timeline reconstruction
- MITRE ATT&CK mapping
- Incident response recommendations
- Final forensic investigation report

## Security

The application incorporates password hashing, authenticated sessions, CSRF protection, secure session cookie configuration, and user-specific access controls.

**Note:** This is an educational cybersecurity project and should undergo further security testing before handling real organizational forensic evidence.
